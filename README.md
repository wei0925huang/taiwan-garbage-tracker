# 三市垃圾車資訊整合 V0.2.1

## 本版功能
- 預設三市整合顯示，並可全選或取消各城市資料。
- 預設顯示動態車輛。
- 新北官方即時 GPS、臺中官方動態車輛、臺北官方表定點位。
- 地標保存在目前裝置的瀏覽器 localStorage，不會同步到雲端。
- 地標可新增、修改、啟用、停用、刪除，並設定時段、半徑及提示音。
- 新北與臺中動態車輛進入地標半徑時播放提示音；臺北表定點位不觸發。
- 電腦版地圖與資料清單等高，清單在面板內捲動；手機版保持地圖在上、清單在下。
