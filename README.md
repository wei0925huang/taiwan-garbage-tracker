# 三市垃圾車資訊整合 V0.2.6

PC 版音效與地標提醒修正：
- 恢復範例的給愛麗絲、少女的祈禱、短嗶聲、雙響聲。
- 新增頁首「測試音效」。
- 地標設定增加「測試提示音」。
- 啟用音效後立即重新檢查範圍內車輛。
- 儲存或修改地標後清除舊狀態並立即重新檢查。
- 接近提醒連續播放，手動關閉或十秒倒數結束才停止。
- 地標刪除前加入確認。
- 保留 V0.2.2 的定位、選點模式、地圖防誤觸與緊湊 PC 布局。

- 修正自動提醒狀態集合更新位置，避免只保留最後一台車。
- 音效啟用時若提醒已顯示，立即接續播放該地標提示音。
- 加入離開半徑 20 公尺遲滯，避免 GPS 邊界漂移重複提醒。


V0.2.5：
- 目前觸發的地標顯示紅色鈴鐺、脈動效果與紅色半徑圈。
- 對應垃圾車顯示紅色外框，並繪製地標到垃圾車的紅色虛線。
- 提醒視窗顯示各地標實際設定的提示音名稱。
- 多筆提醒依佇列逐筆切換圖像，不同時閃爍。
- GitHub Actions 保留手動執行並每 10 分鐘排程同步。
- 來源回傳 0 筆有效座標時，保留上一批有效資料。
- 本更新包不包含 data/*.json，避免覆蓋 GitHub 上的即時資料。


V0.2.6：
- 音效預設啟用，頁首預設顯示「音效已啟用」。
- 每次開啟網頁後，第一次點擊或鍵盤操作會在背景自動解鎖音效，不需專門按啟用按鈕。
- 若提醒已顯示，首次操作解鎖後立即補播該地標提示音。
- 使用者手動靜音後保存設定，下次開啟仍維持靜音。
